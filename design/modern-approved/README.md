# Approved visual direction

Home artwork and icon concept generated with the built-in image generation workflow from the approved two-screen Nepali TimePass concept. Source PNGs are retained here; runtime WebPs live in `app/src/main/res/drawable-nodpi`.

- `home-hero-v1.png`: portrait artwork master, no UI lettering or controls.
- `app-icon-v1.png`: icon master, clapperboard/play symbol with Dhaka-topi motif.
- `home_hero.webp`: responsive landscape reframe of the same home artwork, 1000px wide.
- `timepass_icon_art.webp`: optimized 768px icon artwork. Android applies the adaptive mask; monochrome has its own native vector.

Generated prompts: extract the home cinematic artwork while preserving the two Nepali friends, contemporary outfits, Kathmandu blue-hour setting, clapperboard and cinema tickets; remove UI text and controls. Reframe to 3:2 while retaining full actors for compact phones. Icon prompt: minimal periwinkle/lime clapperboard with play glyph and a coral Dhaka-topi detail on carbon, centered within Android mask safety margins.

These are app artwork assets, not replacements for real film posters. Online posters retain their existing provider and are presented as received.
